# AWS Research

## 1. Brief Overview

Amazon Web Services (AWS) is a cloud computing platform developed by Amazon. It provides a large collection of cloud services that organizations can use for computing, storage, networking, databases, security, analytics, artificial intelligence, and application development.

AWS is one of the major public cloud providers and is designed to support organizations ranging from startups to large enterprises.

## 2. Global Infrastructure

AWS organizes its cloud infrastructure into geographic Regions and Availability Zones.

A Region is a separate geographic area where AWS provides cloud infrastructure. Availability Zones are isolated locations within an AWS Region. Organizations can deploy applications across multiple Availability Zones to improve availability and resilience.

AWS has infrastructure distributed across different parts of the world, allowing organizations to deploy applications closer to their users.

## 3. Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services.

Through the console, users can create, configure, monitor, and manage cloud resources such as virtual machines, storage, databases, networks, and security services.

## 4. Four Core Services

### 4.1 Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers in the AWS cloud. Organizations can use EC2 instances to run websites, applications, databases, and other workloads.

### 4.2 Amazon S3

Amazon Simple Storage Service (S3) is an object storage service. It can be used to store files, images, videos, backups, application data, and other digital objects.

### 4.3 Amazon VPC

Amazon Virtual Private Cloud (VPC) provides networking capabilities for AWS resources. It allows organizations to create isolated virtual networks and configure networking components such as subnets and routing.

### 4.4 AWS IAM

AWS Identity and Access Management (IAM) allows organizations to manage identities and permissions. It controls which users, groups, and applications can access AWS resources.

## 5. Three Advantages

### 5.1 Wide Range of Services

AWS provides many services covering computing, storage, databases, networking, security, analytics, artificial intelligence, and other cloud requirements.

### 5.2 Global Infrastructure

AWS provides cloud infrastructure in different geographic Regions and Availability Zones around the world.

### 5.3 Scalability

AWS resources can be increased or decreased according to workload requirements. This allows organizations to respond to changes in demand.

## 6. Typical Enterprise Use Cases

AWS can be used by enterprises for:

- Web applications
- Mobile applications
- Database hosting
- File and object storage
- Backup and disaster recovery
- Data analytics
- Artificial intelligence and machine learning
- Software development
- Global applications
