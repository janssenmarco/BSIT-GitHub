# Microsoft Azure Research

## 1. Brief Overview

Microsoft Azure is Microsoft's public cloud computing platform. Azure provides cloud services for computing, storage, networking, databases, security, artificial intelligence, analytics, and application development.

Azure is particularly useful for organizations that already use Microsoft technologies.

## 2. Global Infrastructure

Azure organizes its infrastructure into geographic regions and availability zones.

An Azure region is a geographic area containing Azure datacenters. Availability Zones are physically separate locations within an Azure region that have independent power, cooling, and networking infrastructure.

Organizations can use multiple zones to improve application resilience and availability.

## 3. Cloud Management Console

The Azure portal is a web-based interface for managing Microsoft Azure resources.

Users can use the portal to create and manage virtual machines, databases, storage accounts, networks, applications, identities, and other cloud resources.

## 4. Four Core Services

### 4.1 Azure Virtual Machines

Azure Virtual Machines provide virtualized computing resources for running operating systems and applications in the cloud.

### 4.2 Azure Blob Storage

Azure Blob Storage is an object storage service designed for storing large amounts of unstructured data such as documents, images, videos, backups, and application data.

### 4.3 Azure Virtual Network

Azure Virtual Network provides networking capabilities for Azure resources. It allows organizations to create private networks and control communication between cloud resources.

### 4.4 Microsoft Entra ID

Microsoft Entra ID provides identity and access management. It helps organizations manage users and control access to applications and resources.

## 5. Three Advantages

### 5.1 Microsoft Integration

Azure integrates strongly with Microsoft technologies such as Windows Server, Microsoft 365, and Microsoft identity technologies.

### 5.2 Enterprise Support

Azure provides services designed to support enterprise applications, security, identity, databases, analytics, and hybrid environments.

### 5.3 Global Infrastructure

Azure provides cloud infrastructure in many geographic regions around the world.

## 6. Typical Enterprise Use Cases

Azure can be used for:

- Windows Server workloads
- Enterprise applications
- Database hosting
- Microsoft 365 environments
- Identity management
- Hybrid cloud environments
- Web applications
- Data analytics
- Application development
