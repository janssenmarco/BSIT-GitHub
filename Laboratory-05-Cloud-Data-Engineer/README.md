# Laboratory 05 - The Cloud Data Engineer

## Mission Overview

In this laboratory mission, I was assigned to the Cloud Data Engineering Team at CloudNova Technologies. The mission focused on understanding cloud storage and deploying an S3-compatible object storage server using MinIO and Docker.

The goal was to create a proof-of-concept object storage environment for a photo-sharing application. The application needs a reliable place to store a large number of user-uploaded images. To accomplish this, I deployed MinIO, accessed its web console, created a storage bucket named `client-photos`, and uploaded a sample file.

## Objectives

- Differentiate between Block Storage, File Storage, and Object Storage.
- Deploy an S3-compatible Object Storage server using MinIO and Docker.
- Access a cloud service through a web interface using port forwarding.
- Create a storage bucket and upload objects to the cloud.
- Document cloud storage operations using Markdown.
- Continue expanding a professional GitHub Cloud Computing Portfolio.

## Skills Learned

Through this laboratory activity, I learned how to compare different types of cloud storage and identify the appropriate storage type for a specific application. I also learned how to deploy MinIO using Docker and configure the container using environment variables.

I practiced using Docker port mapping to access the MinIO Web Console through port 9001. I also learned how to create an object storage bucket and upload a sample file using the MinIO web interface.

This activity also improved my Linux command-line skills because I used Docker commands to deploy and verify the MinIO container. Finally, I learned how to document technical procedures and organize screenshots and Markdown files in a GitHub Cloud Computing Portfolio.
