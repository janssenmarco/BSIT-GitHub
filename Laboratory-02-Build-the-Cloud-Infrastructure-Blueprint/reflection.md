# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

I think compute resources are one of the most important components of cloud infrastructure because they provide the processing power needed to run applications and services. Without sufficient compute resources, applications would not be able to process requests or perform their required tasks. However, compute also depends on storage and networking to function as part of a complete infrastructure.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a reliable operating system environment for servers and applications. During this laboratory activity, I used Linux commands to investigate the server's operating system, CPU, memory, storage, hostname, and network information. These tools helped me understand how cloud engineers inspect and manage server resources.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it provides a clear record of the infrastructure requirements, configurations, and design decisions. It helps engineers understand the planned system before deployment and reduces the possibility of configuration mistakes. Good documentation also makes troubleshooting and future maintenance easier.

## 4. What new skills did you learn during this laboratory activity?

I learned how to investigate a Linux cloud environment using terminal commands such as `lscpu`, `free -h`, `df -h`, `hostname`, and `ip addr`. I also improved my skills in Markdown documentation, comparing cloud provider services, creating a basic cloud infrastructure diagram, and organizing files in GitHub.

## 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio became more organized and technical after completing this laboratory activity. I added infrastructure documentation, Linux investigation results, cloud provider comparisons, screenshots, and a cloud architecture diagram. This makes my portfolio a better representation of the practical skills I developed in cloud computing.
