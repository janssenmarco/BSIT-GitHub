# Cloud Provider Comparison

## Comparison Table

| Infrastructure Component | Amazon Web Services (AWS) | Microsoft Azure | Google Cloud Platform (GCP) |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network | VPC |
| Identity and Access Management | AWS IAM | Microsoft Entra ID / Azure RBAC | Cloud IAM |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services?

AWS is widely recognized for offering a very broad range of cloud services covering computing, storage, networking, databases, security, analytics, and other technologies. Its extensive service portfolio gives organizations many options when designing different types of cloud solutions.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products?

Microsoft Azure would be a strong choice for an organization that primarily uses Microsoft products. Azure integrates closely with Microsoft technologies and services, including Microsoft Entra ID and Windows-based workloads.

### 3. Which platform is widely recognized for Artificial Intelligence, Machine Learning, and Kubernetes services?

Google Cloud is widely recognized for its capabilities in Artificial Intelligence, Machine Learning, and Kubernetes. Google also has strong expertise in container orchestration through Kubernetes and provides cloud services designed for AI and ML workloads.

### 4. What similarities did you observe among the three cloud providers?

All three providers offer equivalent core infrastructure services, including compute, storage, networking, and identity and access management. Although the service names and implementations differ, their purpose is generally similar: providing scalable infrastructure resources that organizations can access through the cloud.
